# Artifact loss, 2026-09-12 — what survived, what did not, what it costs

## What happened

The session's container restarted. `model/artifacts/` is in `.gitignore`, so it
was never committed and is now **empty**. Uncommitted source edits were lost
too, and the Python environment reset (numpy absent).

## Survived (because it was committed)

| | |
|---|---|
| all code | `model/eval/*.py`, `model/noctua/*.py`, `model/serve/*.py` |
| **the ledger** | `research/ledger.json`, 122 entries — **every number recorded** |
| the rules | `research/RULES.md`, 55 rules |
| research docs | `MECHANISM_MAP`, `TEACHER_ZOO`, `DATASET_AUDIT`, `AUDIT_STATE`, … |
| serving weights | `model/serve/noctua_v2.npz` and siblings |
| serving bundle | `data/noctua_history.parquet` — **9,600 rows, 2025-07-20 → 2026-08-24** |

## Lost (gitignored, unrecoverable here)

- `episodes.parquet`, `episodes_h4.parquet`, `features.parquet` — the 476,362-episode
  walk-forward corpus
- `teacher_oof.npz` — every cross-fitted teacher prediction
- every result artifact: `scorecard_rescaled.json`, `level_report.{json,npz}`,
  `seed_variance.json`, `intraday_basis.json`, `event_window.json`,
  `dst_shift.json`, `mean_level.json`, `benchmark.json`, …
- the 1-minute source series (7,681,837 minutes, 2012 → 2026)

## What this costs, stated plainly

**Every experimental number in the ledger is now unverifiable in this
container.** The numbers are recorded and the code that produced them is
committed, so they are *reproducible in principle* — but not from anything
present here. The 13-month serving bundle cannot rebuild a 2021–2026
walk-forward.

Concretely:
- the two adversarial audits of `P2-level-report-adopt` and
  `P2-scorecard-rescaled-result` lost most of their attack surface mid-flight
  and were re-scoped to static code audits;
- no experiment from this session can be re-run or re-checked here;
- the shipped reporting fix remains **correct as committed code** — that is
  unaffected — but its 6.5 % justification cannot be re-derived locally.

## What it does NOT cost

The decisions. Every verdict, every pre-registered rule, every measured
number and every lesson lives in `ledger.json` and `RULES.md`, both in git.
The research state is intact; only the ability to recompute it from raw data
locally is gone.

## The fix, and it is not "commit the artifacts"

`episodes.parquet` and the 1-minute series are hundreds of MB — they do not
belong in git. What belongs in git, and was missing:

1. **A regeneration path that is tested.** `harvest-assets.yml` already pulls
   exchange data from a runner. An equivalent `rebuild-artifacts.yml` that
   reconstructs `episodes*.parquet` and `features.parquet` from the exchange
   API would make the corpus reproducible rather than precious.
2. **Committed SHA-256 manifests** of each artifact, so a rebuild can be
   verified byte-identical to the one the ledger's numbers came from. Without
   this, a rebuilt corpus is a *different* corpus and R41 applies.
3. **The per-episode arrays behind any headline claim**, committed as small
   `.npz` where they are small enough. `level_report.npz` was ~50 KB and its
   absence is what killed the W-sensitivity audit.
